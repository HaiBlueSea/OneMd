# OneMd 0.2.0

预发布版本，新增本机文档链接。

- 点击预览中的 Markdown 文档链接，在现有 OneMd 窗口中打开；已打开文件直接激活并保留未保存修改。
- PDF 等其他本地文档交系统默认应用处理，不加入 Markdown 文件列表。
- 支持按原文档目录解析相对路径，以及中文／空格、父级／子目录、绝对路径与 `file:///` 链接。
- 文件不存在、不可读或系统无法打开时显示提示；当前文档页内链接仍正常定位。
- 不从链接启动目录、应用包或可执行脚本，不投递远端文件主机；保留图片读取边界。

跨文件标题片段暂不定位；纯文本路径需先写成 Markdown 链接。安装方式与系统要求见 README。仍为 Apple Silicon、macOS 14+、ad-hoc 签名、未经 Apple 公证的预发布版本。

109 项原生回归通过，包含真实 WebKit 点击、链接边界及 33 次资源释放循环；其他文档的系统投递使用测试替身验证，未逐一启动第三方应用。最低系统目标为 macOS 14，当前仅实测 macOS 26.5。
