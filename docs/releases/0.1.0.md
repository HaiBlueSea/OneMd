# OneMd 0.1.0

首个公开预发布候选。基于 MarkView 改造，专注 macOS 本地 Markdown 文件的阅读与编辑。

## 本版能力

- 已打开文件侧栏、批量打开及会话恢复。
- 默认预览，`⌘E` 切换源码／预览双栏，实时渲染与滚动同步。
- Markdown 表格、任务列表、本地图片与 Prism 代码高亮。
- 9 种主题选项、可调字号、可拖动侧栏、宽屏目录。
- 手动保存、外部修改冲突提醒，以及关闭／退出前的未保存确认。
- 修复内嵌 Prism 的语言定义拼接问题，恢复 Swift 等扩展语言的代码高亮。

## 下载与安装

下载 `OneMd-0.1.0-macos-arm64.zip`，解压后将 `OneMd.app` 拖入「应用程序」。需要 **Apple Silicon、macOS 14+**。源码压缩包需自行构建。

可用同一 Release 的 `SHA256SUMS.txt` 校验：

```bash
shasum -a 256 -c SHA256SUMS.txt
```

应用为 **ad-hoc 签名、未经 Apple 公证**。确认来源和校验值后，可按 [Apple 官方说明](https://support.apple.com/en-us/102445) 在「隐私与安全性」中为该应用选择「仍要打开」。若提示恶意软件或完整性损坏，请停止使用并反馈。

## 试用边界

- 早期预发布；Finder 默认关联操作尚未验证。
- 当前仅在 Apple Silicon／macOS 26.5 上运行回归；最低目标为 macOS 14，未逐版本实机验证，Intel 未验证。
- 会话恢复只恢复文件和选中项，未保存的内存草稿不保证在崩溃或强制退出后恢复。
- 远程图片可能联网；应用无内置遥测或文档上传。请脱敏后报告问题。
- 不含目录树、云同步、Mermaid／公式渲染、导出、MCP 或 Quick Look。
