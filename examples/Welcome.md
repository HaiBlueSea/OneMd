# 把注意力留给文字

OneMd · 本地 Markdown 阅读与编辑

> 打开即读，需要时再编辑。你的文档，留在自己的 Mac 上。

## 一个安静的阅读空间

打开项目说明、笔记或设计方案，在左侧切换文档。默认以预览阅读，按 **⌘E** 进入源码与预览双栏，修改后按 **⌘S** 保存。

## 写下想法，立即看到结果

```swift
struct Note {
    let title: String
    let tags: [String]
}

let today = Note(title: "Less noise, more focus", tags: ["Markdown", "macOS"])
```
